# 📁 Scripts

Esta pasta contém scripts utilitários para o projeto TDT IPTV.

## 📋 Conteúdo

- **check_streams.py** - Script para verificar a disponibilidade dos streams IPTV
- **requirements.txt** - Dependências Python necessárias
- **CHECK_STREAMS.md** - Documentação do script de verificação
- **GITHUB_ACTIONS.md** - Guia sobre o workflow de GitHub Actions

## 🚀 Como Utilizar

### Verificar Streams

```bash
# Instalar dependências
pip install -r requirements.txt

# Executar verificação
python check_streams.py
```

Para mais detalhes, consulte [CHECK_STREAMS.md](CHECK_STREAMS.md).
